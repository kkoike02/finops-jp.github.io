# 要件記述フォーマット

## 目的
AI出力の要件ドキュメントを、そのままチームレビューに回せる品質にする。

## ルール

### ユーザーストーリー形式
すべての要件は以下のフォーマットで記述すること：

```
### REQ-XXX: [要件タイトル]

**As a** [ユーザー種別]
**I want to** [やりたいこと]
**So that** [得られる価値]

#### 受入条件
- [ ] [条件1: 具体的で検証可能な記述]
- [ ] [条件2: 具体的で検証可能な記述]

#### 前提条件
- [前提1]

#### 制約事項
- [制約1]
```

### 用語集の参照
要件で使用する用語は `docs/glossary.md` の定義に従うこと。
用語集に存在しない新規用語を使う場合は、要件ドキュメント末尾の「新規用語」セクションに定義を追記すること。

### 必須セクション
要件ドキュメントには以下のセクションを必ず含めること：
1. 概要（1-2文で変更の目的）
2. 背景（なぜこの変更が必要か）
3. スコープ（対象範囲と対象外の明示）
4. 要件一覧（ユーザーストーリー形式）
5. 非機能要件（該当する場合）
6. 影響範囲（S02の影響分析テンプレートを使用）
