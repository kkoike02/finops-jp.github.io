# Confluence転記フォーマット

## 目的
AI出力のMarkdownをConfluenceへ最小限の手作業で転記可能にする。

## ルール

### Confluence互換構造
- 見出し: `##` = h2、`###` = h3（`#` h1はページタイトルに使用しない）
- テーブル: Markdown標準テーブル形式（Confluenceマクロで変換可能）
- コードブロック: 言語指定付き（Confluenceコードマクロに対応）
- Mermaid図: そのまま記述（Confluence Mermaidプラグインで表示）

### メタデータヘッダー
ドキュメント先頭に以下のメタデータを付与すること（Confluence転記時の情報として）：

```markdown
<!-- Confluence転記情報
スペース: [スペースキー]
親ページ: [親ページタイトル]
ラベル: [label1, label2]
最終更新: YYYY-MM-DD
ステータス: ドラフト / レビュー中 / 承認済み
-->
```

### 画像・図表
- Mermaid図はそのまま記述（プラグイン対応）
- 外部画像参照は使用しない（Confluence添付ファイルを前提）
- 図のaltテキストを必ず付与

### ステータスマクロ対応
ドキュメント冒頭に以下のステータス表示を含めること：

```markdown
**ステータス**: 🟡 ドラフト / 🔵 レビュー中 / 🟢 承認済み
```

### セクション間リンク
Confluence内の他ページへのリンクは以下の形式で記述：

```markdown
参照: [ページタイトル](confluence://スペースキー/ページタイトル)
```
