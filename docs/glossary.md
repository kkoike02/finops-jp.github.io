# 用語集（Glossary）

プロジェクトで使用する用語の定義です。
要件・設計ドキュメントではこの用語集に従って記述してください。

## FinOps関連用語

| 用語 | 定義 |
|------|------|
| FinOps | クラウドの財務管理を最適化するための運用フレームワーク |
| コスト配分（Allocation） | クラウドコストを組織単位やプロジェクトに割り当てること |
| ショーバック（Showback） | コストを可視化して関係者に報告すること（請求はしない） |
| チャージバック（Chargeback） | コストを実際に事業部門に請求すること |
| リザーブドインスタンス（RI） | 長期利用を前提とした割引購入契約 |
| Savings Plans | 一定の使用量をコミットすることで得られる割引プラン |
| 単位経済性（Unit Economics） | ビジネス単位あたりのクラウドコスト |
| 異常検知（Anomaly Detection） | コストの異常な変動を検出すること |
